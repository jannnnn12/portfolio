## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.

The page loads Tailwind CSS, Font Awesome, and the Inter font from external CDNs, so an internet connection is needed for those resources.

## Deploy with GitHub Pages

1. Push the portfolio files, including `index.html` and the `img` folder, to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing the portfolio and the `/ (root)` folder, then save.
5. After GitHub Pages finishes deploying, open the URL shown in the Pages settings.
